1. 시작하기

가입과 로그인

  1. 사이트(또는 앱)를 열고 회원가입을 누릅니다.
  2. 사용자 이름은 영문·숫자 8~24자(밑줄 _은 한 번만), 비밀번호는 영문과 숫자를 섞어 8~32자로 정합니다.
  3. hCAPTCHA 인증과 개인정보 처리방침 동의 후 가입하면 바로 로그인됩니다.

이메일·전화번호는 받지 않습니다. 비밀번호를 잊으면 되찾을 방법이 제한되니 안전한 곳에 보관하세요. 로그인에 여러 번 실패하면 잠시 기다린 뒤 다시 시도해야 합니다.

  • 휴대폰·태블릿: 키보드의 줄바꿈(↵) 키는 항상 줄을 바꾸고, 보내기는 입력창 오른쪽 보내기 버튼으로만 합니다.
  • 답변 중에는 보내기 버튼이 중지 버튼으로 바뀝니다.

첨부와 음성

  • 클립 버튼, 붙여넣기 또는 끌어다 놓기로 파일·이미지를 첨부합니다. 첨부한 파일은 채팅 프로젝트의 upload/ 폴더에도 들어갑니다.
  • 마이크 버튼은 말한 내용을 글로 바꿔 보내고, LIVE는 음성으로 계속 대화합니다. 인식 언어·읽기 목소리·자동 읽기는 설정 → 기타 설정에서 바꿉니다.

답변 다루기

  • 코드 블록 오른쪽 위 복사 버튼으로 코드를 복사합니다. 긴 줄은 블록 안에서 좌우로 밀어 봅니다.
  • AI가 만든 파일 카드에서 미리보기·원문·편집·다운로드를 할 수 있습니다. HTML은 분리된 미리보기 창에서 안전하게 실행됩니다.
  • 상단 공유 버튼으로 읽기 전용 공유 링크를 만들고, 새 링크로 바꾸거나 공유를 중지할 수 있습니다.
  • 메모리를 켜 두면 AI가 대화에서 기억할 만한 내용을 저장합니다. 설정 → AI → 메모리 관리에서 보고 고치거나 지울 수 있습니다.

4. 토큰과 코드 교환

  • AI를 부를 때마다 사용한 양만큼 토큰이 차감됩니다. 남은 토큰은 상단과 사이드바 아래에 표시됩니다.
  • 일일 토큰은 매일 00:00(한국 시간)에 기본값으로 다시 채워집니다. 쓰고 남은 양은 이월되지 않습니다.
  • 보너스 토큰은 코드 교환·이벤트로 받은 토큰으로, 날짜가 바뀌어도 남습니다. 일일 토큰을 먼저 쓰고 부족하면 보너스에서 차감됩니다.
  • 사용량 → 코드 교환에 받은 코드를 입력하세요. 틀린 코드를 연속으로 입력하면 잠시 기다려야 합니다.

토큰이 부족하면 답변이 시작되지 않습니다. WORK의 높은 단계(DEEP·ULTRA)는 최소 차감량이 더 큽니다. 정확한 기준은 사용량 → 토큰의 차감 기준에 나옵니다.

5. Sandbox Linux

브라우저 안에서 동작하는 리눅스 비슷한 파일·명령 환경입니다. 상단 터미널 버튼이나 작업공간 → 터미널 열기로 엽니다. 파일은 이 브라우저(기기)에 저장되고, 서버 파일은 필요할 때만 불러옵니다. 실제 Linux 프로그램(python, npm, git 등)은 실행되지 않습니다 — 이런 작업은 안드로이드 앱의 Local에서 하세요.

채팅마다 프로젝트 폴더

/user/projects/<채팅 이름-식별자>/
  upload/    ← 첨부한 파일
  outputs/   ← AI가 만든 결과물

채팅을 열면 해당 프로젝트 폴더가 현재 위치가 됩니다. AI 도구가 /user/upload, /user/download를 쓰면 각각 현재 프로젝트의 upload/, outputs/로 연결됩니다.

주요 명령

명령설명

mkdir -p, touch, cp -r, mv만들기, 복사, 이동·이름 변경

sort, uniq, cut, tr, base64텍스트 가공 (파이프 |와 > 저장 지원)

휴대폰에서는 터미널 아래 보조 키 줄(Tab, ↑, ↓, Ctrl+C, /, | 등)을 쓸 수 있습니다. Tab은 명령·경로 자동 완성입니다.

상단 복사 버튼은 선택한 부분을, 선택이 없으면 터미널 로그 전체를 복사합니다. 오류를 문의할 때 그대로 붙여 넣으면 됩니다. 채팅의 도구 출력에도 복사 버튼이 있습니다.

6. 파일 탐색 · 휴지통 · 백업

Sandbox 상단의 파일 버튼으로 파일 트리를 엽니다. 파일이 하나도 없는 폴더는 접힌 상태로 열려, 파일이 있는 곳만 바로 보입니다. 폴더를 누르면 펼치고, 한 번 더 누르면 접습니다.

  • 파일·폴더의 ⋯ 메뉴(또는 길게 누르기/오른쪽 클릭): 열기, 원문 보기, 이름 변경, 잠금, 백업, 다운로드, 서버로 전송, 삭제
  • 잠금한 항목은 AI가 바꾸거나 지울 때 확인을 받습니다.
  • 백업은 AI가 접근할 수 없는 별도 사본입니다. ⋯ → 백업 목록에서 복원합니다.
  • 업로드 버튼으로 파일이나 폴더를 통째로 올릴 수 있고, ZIP·TAR 압축은 풀어서 넣을 수 있습니다.

휴지통

  • 지운 파일·폴더는 바로 사라지지 않고 휴지통으로 가서 7일 동안 보관된 뒤 자동 삭제됩니다.
  • 채팅을 삭제하면 그 채팅의 프로젝트 폴더(첨부·결과물 포함)도 휴지통으로 옮겨집니다. 서버에만 있던 파일은 삭제 직전에 기기로 받아 함께 보관합니다.
  • 파일 트리의 ⋯ → 휴지통에서 항목별 복원·영구 삭제, 또는 전체 비우기를 할 수 있습니다. 복원하면 원래 경로로 돌아갑니다(같은 이름이 있으면 "(2)"가 붙습니다).
  • 휴지통도 Sandbox 저장공간(100MB)에 포함됩니다. 공간이 모자라면 휴지통을 비워 주세요.

서버 파일

작업공간 → 서버 파일 관리(또는 파일 트리의 구름 버튼)에서 서버에 저장된 파일을 검색하고, 여러 개를 골라 가져오기·ZIP 다운로드·삭제할 수 있습니다. 서버 삭제는 되돌릴 수 없습니다.

7. 승인과 안전 규칙

AI가 파일을 바꾸거나 명령을 실행하기 전에, 대화 맨 아래에 작은 승인 카드가 나타납니다. 허용 또는 거부를 누르면 되고, 중지 버튼을 누르면 자동으로 거부됩니다.

승인 강도동작
수동읽기·목록·검색·간단한 ls/cd만 자동. 편집·명령 실행은 매번 확인
자동파일 편집 등은 자동. 다운로드·삭제·알 수 없는 명령·코드 실행은 확인
전체일반 작업은 추가 확인 없이 실행 (아래 규칙은 그대로 적용)

웹사이트에서는 승인 강도가 수동으로 고정되고 선택 막대가 보이지 않습니다. 승인 강도를 바꾸는 기능은 안드로이드 앱에만 있어요. 앱에서 전체로 바꿀 때와 화면 조작을 켠 작업을 시작할 때는 웹 화면이 대신 누를 수 없는 시스템 확인 창이 뜹니다. 전체 승인이어도 화면 조작은 앱마다 한 번 확인하고, KkibokAI 자신·설정 앱·시스템 화면은 AI가 조작하지 않습니다.

명령 시간 제한

AI는 명령마다 시간 제한을 정합니다. 기본은 Sandbox 60초, 앱의 Local 300초이고, 설치·빌드처럼 오래 걸리는 명령은 AI가 늘립니다(최대 Sandbox 10분, Local 1시간). 시간이 지나면 명령을 멈추고 그때까지의 출력과 종료 코드 124를 AI에게 돌려줍니다. 서버처럼 끝나지 않는 명령은 백그라운드로 실행하도록 안내되어 있습니다.

승인 강도와 상관없이 적용되는 규칙

  • 차단 비밀번호·토큰·시크릿 설정, 인증 정보 파일(~/.ssh, .netrc 등) 읽기·쓰기는 AI가 절대 하지 않습니다. 필요하면 직접 설정하세요. 파일 검색 결과에도 이런 파일과 .env는 나오지 않습니다.
  • 직접 동의 .env 같은 비밀 값 파일 읽기, 셸 시작 파일(.profile, .bashrc)·git hooks·git 설정 변경, 명령 결과를 외부로 보내는 명령, 동적 SQL·함수 생성도 매번 묻습니다.
  • 직접 동의 Supabase 함수 배포·삭제, 저장소 삭제, 강제 푸시, 넓은 범위 삭제(rm -rf), 프로덕션 배포 같은 중요 작업은 전체 승인이어도 붉은 카드로 다시 묻습니다. 앱에서는 웹이 대신 누를 수 없는 시스템 확인 창으로 묻습니다.
  • 로컬(기기) 파일을 서버로 올리는 작업은 매번 동의를 받습니다. 거부하면 파일은 기기에만 남습니다.

8. 도구 연결

설정 → AI → 도구 연결에서 GitHub, Supabase, Vercel, Netlify 토큰을 등록하면 AI가 해당 서비스에서 작업할 수 있습니다. 토큰은 서버에 암호화되어 저장되며, 연결을 해제하면 바로 지워집니다. 변경 작업은 항상 승인 카드를 거칩니다. 최소 권한 토큰을 쓰는 것을 권장합니다.

9. 안드로이드 앱

설치

  1. 최신 APK 다운로드 후 설치합니다(출처를 알 수 없는 앱 설치 허용 필요).
  2. 앱은 이 사이트 화면을 그대로 불러오므로, 사이트가 업데이트되면 앱도 바로 바뀝니다. 인터넷이 없으면 앱에 들어 있는 화면으로 엽니다.
  3. 앱 0.7.0부터는 자동 업데이트됩니다. 앱을 열 때 새 버전이 있으면 자동으로 받아 설치 확인 창을 띄우고, "업데이트"만 누르면 됩니다(처음 한 번은 'KkibokAI의 앱 설치 허용'을 켜야 해요). 설정 → 기타 설정 → 앱 업데이트에서 직접 확인할 수도 있어요.
  4. 0.6.0 이하를 쓰고 있다면 최신 APK를 한 번만 직접 설치해 주세요.

Sandbox와 Local

SandboxLocal (앱 전용)

권한

작업공간 → 권한 및 작업 설정에서 필요한 것만 켭니다: 알림(답변 완료), 마이크(음성), 다른 앱 위에 표시·접근성(화면 조작). 화면 조작을 켜면 현재 화면의 스크린샷과 텍스트가 서버와 AI 제공자에게 전달됩니다.

10. 로컬 터미널 · 로컬 파일

로그인한 상태에서 상단 터미널 버튼(또는 작업공간 → 로컬 터미널)을 누릅니다. 처음 한 번은 Linux를 설치하느라 시간이 걸립니다.

  • + 버튼으로 세션을 추가합니다(동시에 최대 12개). 위쪽 탭으로 세션을 오갑니다.
  • 화면을 닫아도 세션은 백그라운드에서 계속 실행됩니다. 끝내려면 세션 종료, 전부 끝내려면 알림의 모두 종료를 누르세요.
  • 세션 추가가 실패하면 터미널 위쪽 상태 문구와 화면에 실패 이유가 나옵니다. 다시 + 를 눌러 재시도할 수 있습니다.
  • 복사 버튼: 선택한 부분 또는 현재 세션의 로그 전체를 복사합니다.
  • 터미널에 입력할 때는 키보드 단어 추천·자동 수정이 꺼지고, 누르는 글자가 바로 입력됩니다. 이 때문에 키보드에 따라 터미널 입력 중에는 영문만 입력될 수 있어요(한글은 복사해 붙여 넣기).
pkg update
pkg install python nodejs git curl
python -c "print('Python works')"
mkdir -p /user/my-app && cd /user/my-app
python -m http.server 8080      # 다른 세션에서 curl http://127.0.0.1:8080

로컬 파일 (작업 폴더)

작업공간 → 로컬 파일에서 앱 작업 폴더(/user)를 터미널 없이 둘러볼 수 있습니다.

  • 폴더 이동, 새 폴더·새 파일 만들기, 텍스트 파일 열기·편집·저장
  • 휴대폰의 파일을 작업 폴더로 가져오기, 작업 폴더의 파일을 휴대폰에 내보내기(저장 위치 선택)
  • 이름 변경과 삭제(확인 후 영구 삭제)

로컬 파일은 기기에만 저장되며, 앱을 삭제하면 함께 지워집니다. 중요한 파일은 내보내기로 따로 보관하세요.

11. 문의 · 계정 찾기

문의하기

사이드바의 도움말·문의, 또는 로그인 화면 아래 문의하기에서 보냅니다. 로그인하지 않아도 보낼 수 있어요.

  1. 빠른 문의(비밀번호를 잊었어요, 오류가 생겼어요 등)를 누르면 분류와 내용 서식이 자동으로 채워집니다.
  2. 또는 메인 분류(계정·신고·질문·기타)와 세부 분류를 고르고 내용을 적습니다.
  3. hCAPTCHA 인증 후 문의 보내기. 비밀번호는 절대 적지 마세요.
  • 로그인한 상태라면 답변을 문의 → 내 문의에서 보고, 앱에서는 알림으로도 받습니다.
  • 로그인하지 않았다면 문의 번호와 확인 코드가 나옵니다. 문의 확인에서 이 두 가지로 답변을 보고 추가 메시지를 남길 수 있어요. 같은 기기에서는 자동으로 기억하지만 꼭 따로 적어 두세요.
  • 도배를 막기 위해 1시간에 5건까지 보낼 수 있습니다.

사용자 이름 또는 비밀번호를 잃었을 때

로그인 화면의 사용자 이름 또는 비밀번호를 잃었어요를 누릅니다.

  • 사용자 이름 찾기: 이름을 바꾼 적이 있다면 변경 전 이름과 현재 비밀번호로 지금 이름을 확인할 수 있어요. 다른 사람이 옛 이름만으로 새 이름을 알아내지 못하도록 비밀번호도 함께 확인합니다.
  • 이름을 바꾼 적이 없거나 비밀번호도 모르면 문의로 찾습니다.
  • 비밀번호 찾기는 문의로 진행됩니다. 운영자가 계정을 확인한 뒤 문의 답변으로 임시 비밀번호를 알려 드리니, 로그인 후 바로 새 비밀번호로 바꿔 주세요. 계정 확인을 위해 가입 시기, 최근 채팅 제목, 고유 ID 같은 정보를 적어 주면 빨라요.

12. 계정 알림 (안드로이드 앱)

앱에서는 계정에 중요한 변화가 생기면 휴대폰 알림으로 알려 줍니다. 기본으로 켜져 있고, 설정 → 기타 설정 → 알림에서 끄고 켤 수 있어요.

  • 사용자 이름 변경, 비밀번호 변경, 모든 기기 로그아웃, 새 로그인, 도구 연결 추가·해제, 문의 답변, 운영자 알림
  • 다른 기기에서 비밀번호가 바뀌어 이 기기가 로그아웃돼도 알림은 받을 수 있습니다. 직접 로그아웃하면 이 기기의 알림은 꺼집니다.
  • 앱을 열 때 바로 확인하고, 앱을 닫아 두어도 약 15분마다 확인합니다(배터리 절약 상태에 따라 늦어질 수 있음).
  • 계정 → 최근 계정 활동에서도 최근 기록을 볼 수 있어요. 본인이 하지 않은 변경이 보이면 바로 비밀번호를 바꾸고 문의해 주세요.

14. 자주 묻는 질문

업데이트가 바로 안 보여요

새로고침(앱은 다른 앱에 갔다가 돌아오기)을 해 주세요. 입력 중이거나 AI가 답변 중일 때는 앱이 자동으로 새로고침하지 않습니다.

휴대폰에서 Enter를 누르면 메시지가 보내져요

휴대폰·태블릿에서는 Enter가 항상 줄바꿈입니다. 그래도 보내진다면 페이지를 새로고침해 최신 버전인지 확인해 주세요.

코드 블록 위에서 화면이 안 내려가요

최신 버전에서 고쳐졌습니다. 코드 블록 위에서 위아래로 밀면 대화가 스크롤되고, 좌우로 밀면 긴 코드 줄이 스크롤됩니다.

로컬 터미널에 "runtime/…tar.gz" 오류가 나와요

앱 0.5.0 이하에서 앱 내부 Linux 이미지를 찾지 못하던 문제입니다. 최신 APK로 업데이트하면 해결됩니다.

실수로 채팅을 지웠어요

대화 내용은 되돌릴 수 없지만, 그 채팅의 프로젝트 파일은 7일 동안 Sandbox 휴지통에 남아 있습니다. Sandbox → 파일 → ⋯ → 휴지통에서 복원하세요.

Sandbox에서 python, npm이 안 돼요

Sandbox는 브라우저 안의 가상 환경이라 실제 프로그램을 실행하지 않습니다. 안드로이드 앱에서 Local 작업 공간과 로컬 터미널을 사용하세요.

AI가 비밀번호나 API 키를 설정해 주지 않아요

안전 규칙상 AI는 비밀번호·토큰·시크릿을 설정하지 않습니다. 해당 서비스의 설정 화면에서 직접 입력해 주세요.

화면이 빨리 열리던데, 최신 정보가 맞나요?

마지막으로 받은 화면 파일과 계정 정보를 기기에 저장해 두었다가 바로 보여 주고, 뒤에서 서버의 최신 정보로 곧바로 바꿉니다. 새 버전이 나오면 자동으로 새로고침되거나 "새 버전이 준비됐어요" 안내가 나옵니다. 인터넷이 끊겨도 마지막 화면은 열립니다.

터미널에서 한글이 입력되지 않아요

터미널은 글자가 바로 입력되도록 키보드 추천을 끈 모드를 씁니다. 이 모드에서는 키보드에 따라 영문만 입력될 수 있어요. 한글은 다른 곳에서 복사해 붙여 넣어 주세요.

토큰이 다 떨어졌어요

일일 토큰은 매일 00:00(한국 시간)에 다시 채워집니다. 받은 교환 코드가 있으면 사용량 → 코드 교환에 입력하세요.
